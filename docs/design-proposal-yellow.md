## 整体概念

保留「帖」的核心概念与「留一个空格，让这次重逢自己填上」的情感主线，将整体配色改为深墨绿体系：深墨绿作为礼盒盖面、标签上带与卡片题头的封面色，承载大面积空场；暖米白转为可书写内页、标签手写面板和背标信息底；低饱和桂黄只用于单枝桂花线描与少量花簇点缀。主题字「重逢帖」仍以小字号、克制排版出现，不压手写线。瓶身标签、礼盒盖面、纪念卡共用同一单枝桂花细线描母版，桂花只作秋日视觉线索，不暗示桂花风味，也不出现「桂花酿」「桂花黄酒」等字样。同一版式通过使用者或主办方后填信息，适配不同届别与年份，不做可扩展多瓶结构，不做满版花团。墨绿与暖米白的分配是设计选择，不作为文化考据或风味依据。

确认：人群为参加校友聚会的成年人；场景为聚会现场作为赠礼发放，餐后带走；用途为回家后作为纪念摆件或收藏，并可在标签和卡片上填写姓名、届别、日期、地点。假设：聚会规模在数十至数百份量级，优先采用一次性定稿印刷与留白填写；具体数量、年龄构成与饮酒偏好尚未确认。

本方案沿用冻结来源中的策划创意，不是史料考证，也不添加具体历史典故。来源故事把重逢理解为「一件需要被写下日期的事」；本方案在此基础上的原创视觉细化为：以「帖」的留白与短横线起笔位承接书写动作，以深墨绿作封面空场、暖米白作可书写内页，以单枝桂花细线描点出秋日意象，以纪念卡承接姓名、届别、日期与地点。桂花仅作视觉线索，不代表酒体风味，也不作为配方依据；情感主线仍是「留一个空格，让这次重逢自己填上」。本次修订仅调整配色，不改变来源故事与产品方向。

## 视觉设计

**故事与视觉转化（策划建议）**

- **重逢需要一个被记录的日期** → 标签正面下部的暖米白横向手写面板，左侧设深墨绿短横线作起笔位，面板上方以深墨绿小字写引导短句，留白高度按最终标签尺寸调整 → 瓶身正面标签下部的暖米白书写区

  表达理由：同一版标签可适配不同届别与年份，只需后填即可，减少因人数或届别变化而反复改版

- **桂花作为季节与气味的视觉暗示，而非配方承诺** → 深墨绿底上的单枝桂花细线描，采用低饱和桂黄，线宽分主枝与花簇两级，花簇稀疏，不出现花朵满铺，也不出现「桂花酿」「桂花黄酒」等字样 → 礼盒盖面左上角向右中延伸，瓶身背标角落缩小使用

  表达理由：点题但不引导饮用者对风味产生预期，为商家后续是否调整风味保留余地

- **纪念卡是「帖」，被收藏而非被丢弃** → 与盒面同款的暖米白卡片，正面以深墨绿题头承接「重逢帖」，正面留姓名与届别，背面留日期与地点 → 礼盒内衬上层卡槽，卡槽位置仅作建议，宜略高于瓶肩以避免取出折角

  表达理由：以低成本纸质件承接书写动作，强化「带走纪念」而非「当场消耗」

- **克制版面让使用者完成最后书写** → 深墨绿大面积封面空场、暖米白可书写面板、小字号主题字与深墨绿短横线起笔位，主题字不压手写线 → 盒盖面与标签正面

  表达理由：让空场与书写面成为主体，使使用者成为纪念信息的最后作者

**图案与构图**

整体以深墨绿作封面空场，暖米白作书写场，低饱和桂黄作单枝线描。主体是单枝桂花线描、小字号主题字「重逢帖」与可书写暖米白面板。盒盖面建议深墨绿占 70%–80%，作为空场；单枝桂花从左上角约 10% 位置向右中延伸，占版面约 20%–25%；主题字置于左上花枝起笔附近或中上偏左，占版面约 8%–12%，用暖米白，不压花枝；不设满版花团。标签正面建议上部 22%–28% 为深墨绿题头带，主题字置于带内；中部至下部 50%–58% 为暖米白手写面板，引导短句置于面板上沿靠左，左侧约 6%–8% 处设深墨绿短横线起笔位，底边 6%–8% 为深墨绿细边或窄带。背标建议暖米白底占 70%–80%，上带 15%–20% 为深墨绿，桂花小图缩至背标宽度的 18%–22%，下部约 65%–70% 为法定文案信息占位框。纪念卡正面建议上部 28%–32% 为深墨绿题头放主题字与缩小桂花，下部 60%–65% 为暖米白书写区放姓名与届别；背面建议暖米白底为主，上下或四周边框用深墨绿细线，上部约 18%–20% 放日期与地点字段，下部约 70% 为留白。所有比例为建议，最终按瓶型、盒型与卡片尺寸校核。

**配色建议**

- 主色：桂影墨绿 `#2E4636` — 礼盒盖面主底，建议占盖面 70%–80%；标签正面题头带与底边，建议占标签正面 28%–36%；纪念卡正面题头，建议占卡面 28%–32%；同时用于暖米白底上的主题字、字段线和小字，文字面积不超过各浅底版面 8%–12%

- 辅助色：暖米白 `#F3EEE4` — 标签正面手写面板，建议占标签正面 50%–58%；纪念卡正面下部书写区和背面主书写面，建议占卡面 60%–70%；背标信息底约 70%–80%；深墨绿底上的主题字与信息文字使用此色

- 点缀色：低饱和桂黄 `#B68B43` — 仅用于单枝桂花线描与少量花簇点缀，不用于大面积底色或法定信息；建议占图案面积不超过 15%–20%，整体版面不超过 3%–5%。桂黄为印刷色建议，不默认烫金或金属工艺

HEX 为概念配色建议，实际印刷与面料表现待打样确认。

**字体与文字层级**

建议采用可商用授权的宋体或楷体类字体，不指定既有品牌字体。主题字「重逢帖」用中等字重宋体，深墨绿底上使用暖米白，置于盒盖面上部偏左或标签正面深绿题头带内，字号克制，不压手写线；引导短句用轻量楷体或细宋体，浅底上用深墨绿，字号小于主题字；姓名、届别、日期、地点字段用细黑体或宋体，左对齐，浅底上用深墨绿，保持可读；背标法定文案用细黑体或宋体另设信息层级，字号与行距待合规文案和标签尺寸确认。最终字库选择与授权状态待确认，不在本提案中假定已获授权。

**文案示例**

- 「重逢帖」：礼盒盖面深墨绿底上部偏左，用暖米白；标签正面深墨绿题头带内，用小字号暖米白（主题字，一级文字）

- 「写下这次重逢的日期」：标签正面暖米白手写面板上沿，靠左对齐，用深墨绿（手写引导短句，二级文字）

- 「姓名 / 届别」：纪念卡正面暖米白书写区上沿，用深墨绿细字（填写字段引导，三级文字）

- 「日期 / 地点」：纪念卡背面暖米白书写区上沿，用深墨绿细字（填写字段引导，三级文字）

- 「〔法定文案占位〕」：瓶身背标暖米白信息区下部约 65%–70%（等待商家提供并经确认的法定文案占位，不代拟内容）

## 产品应用与交付

**核心应用**

### 瓶身标签概念设计稿

交付标识：D1

版式：正面标签上部 22%–28% 为深墨绿题头带，小字号「重逢帖」用暖米白置于带内；其下 50%–58% 为暖米白横向手写面板，「写下这次重逢的日期」用深墨绿置于面板上沿靠左，左侧约 6%–8% 处设深墨绿短横线起笔位；底边 6%–8% 为深墨绿细边或窄带。主题字和引导语均不压手写线。背标独立分区：暖米白底占 70%–80%，上带 15%–20% 为深墨绿，缩小桂花小图置于上带端部，下部约 65%–70% 为法定文案信息占位框。正面与背标关系清楚，不把信息混排到正面留白区；尺寸与瓶型待确认，版式按可适配框架推进。

图案：正面不铺桂花，保留可书写面积；背标上带端部放置缩小单枝桂花线描，桂花线用低饱和桂黄，占背标宽度约 18%–22%，花簇稀疏，不出现满版花团。

文字：采用「重逢帖」置于标签正面深墨绿题头带内、「写下这次重逢的日期」置于暖米白手写面板上沿、「〔法定文案占位〕」置于背标暖米白信息区；姓名、届别、日期不印死，保留手写空间。

材料与工艺建议：建议不干胶标签纸，哑光或半哑光面，先做可书写测试；深墨绿大面积印刷与桂黄细线对比需打样确认。尺寸、胶材、印刷工艺与耐摩擦性待瓶型和报价确认，不将烫印、专色或特殊纸列为默认工艺。实际表现需打样。

### 礼盒盖面概念设计稿

交付标识：D2

版式：盖面以深墨绿为底，空场建议占 70%–80%；单枝桂花从左上角约 10% 位置向右中细线延伸，占版面约 20%–25%，桂花线用低饱和桂黄；「重逢帖」用暖米白置于左上花枝起笔附近或中上偏左，占版面约 8%–12%，不压花枝。盒盖内侧保持简洁，不作整面书写层；内衬只作单瓶固定与卡槽功能示意，卡槽建议位于瓶肩上方偏侧，具体结构与固定方式由包装供应商确认。

图案：单枝桂花线描为唯一主图形，在深墨绿底上以低饱和桂黄呈现，线宽分主枝与花簇两级，花簇不过密；不做满版花团，不添加无关插画或装饰性夹层。

配色：#2E4636、#F3EEE4、#B68B43

文字：盖面采用「重逢帖」作为主题字，用暖米白置于深墨绿底上；不添加风味或功效用语。盒盖内侧不设核心文案，如需书写面另作可选延展。

材料与工艺建议：建议硬质翻盖礼盒，深墨绿裱纸或同等深绿纸面，暖米白内衬或简洁功能内衬；盒型档位、纸板厚度、内衬材质与运输固定待报价和供应商确认，不默认烫金、专色或特殊纸。桂黄线描为印刷色建议，大面积墨绿均匀性与耐摩擦需打样检查。

### 纪念卡双面设计稿

配色：#2E4636、#F3EEE4、#B68B43

文字：正面采用「重逢帖」「姓名 / 届别」，背面采用「日期 / 地点」；主题字与字段引导均为示例文案，最终由商家确认。

### 单枝桂花线描母版与应用标注页

文字：标注页内使用「重逢帖」「写下这次重逢的日期」「姓名 / 届别」「日期 / 地点」「〔法定文案占位〕」作为应用示例；禁用词示例单独列出，不作为包装文案。

- 假设聚会规模在数十至数百份量级，因而优先采用一次性定稿印刷与留白填写；验证方式：先确认数量区间，数量未定时不做届别专属版面。
- 假设现有瓶型可容纳正面深绿题头带与大面积暖米白手写面板；验证方式：取得瓶型与标签可印尺寸后做 1:1 纸样，检查可写面积和文字可读性。
- 假设硬质翻盖礼盒与简洁功能内衬在预算范围内可实现；验证方式：向包装供应商询价并取得材料样，报价前不将烫印、特殊纸等列为默认。
- 假设标签与卡片以使用者自填为主，主办方代填为可选方式；验证方式：由主办方确认填写方式，未确认前不印死姓名、届别、日期和地点。
- 假设桂花仅作为视觉意象，酒体风味是否调整由商家另行决定；验证方式：商家确认风味方向，本方案不依赖该决定，画面不写风味承诺。
- 假设纪念卡先按接近 85×120 mm 的竖版比例框架推进；验证方式：待商家确认成品尺寸与书写面材料后校核文字大小和留白空间。
- 深墨绿为主色、暖米白用于书写区、低饱和桂黄仅作线描点缀；验证方式：打样检查深墨绿与暖米白的文字对比度、暖米白手写可读性、大面积墨绿色差和桂黄细线表现，结果仅用于设计修订。
- 桂黄为印刷色建议，不默认烫金或金属工艺；验证方式：报价与打样阶段确认是否采用普通印刷、专色或其他工艺，未确认前不写成既定工艺。
- 盒盖内侧可书写面未列为本轮核心包装内容；如商家后续确认需要，再作 optional 延展，不改变主体留白结构。
- 本方案中的材料、尺寸比例、工艺、字体与配色均为建议；HEX 不是确认印刷色，实际表现需打样，不承诺生产可行性、销量或书写效果。

## 后续确认

- **确认预算区间与数量级，用于判断硬质翻盖礼盒档位和是否加印届别信息**（商家决定）

  建议责任：主办方/校友会与商家；时点：报价与印刷定稿前

  推进方式：先按可适配版式和普通硬质翻盖礼盒做概念，数量未定时不印专属届别；预算明确后再决定盒型档位与加印范围。

- **提供瓶型、容量与标签可印尺寸**（资料补齐）

  建议责任：商家产品负责人/包装供应商；时点：标签版式细化前

  推进方式：先做可适配版式与深绿题头带、暖米白手写面板的比例框架，尺寸到位后校核面板高度、背标信息区和文字大小。

- **确认礼盒结构、内衬固定方式与运输防晃方案**（商家决定）

  建议责任：包装供应商与商家；时点：打样前

  推进方式：先按硬质翻盖盒和简洁功能内衬做概念示意，卡槽位置仅作建议；结构与材料确认后再细化防晃和取卡动线。

- **提供品牌文件及经确认的背标法定文案与信息区要求**（资料补齐）

  建议责任：商家品牌/合规负责人；时点：盒面与标签印刷定稿前

  推进方式：先以无品牌占位版式和背标暖米白信息区框位推进构图与线描母版，不自行编造品牌标识，不代拟法定文案；资料到位后替换占位并排版。

- **确认标签与纪念卡的留白填写方式及日期、届别、地点字段处理**（商家决定）

  建议责任：主办方/校友会；时点：标签与卡片版式细化至印刷定稿前

  推进方式：先按可手写留白和可选印刷字段设计，未确认前不印死姓名、日期和届别；如选择主办方代填，再增加补充版式，不改变主体留白结构。

- **确认纪念卡成品尺寸与书写面材料**（资料补齐）

  建议责任：商家/包装供应商；时点：纪念卡排版细化前

  推进方式：先按接近 85×120 mm 的竖版比例框架推进，尺寸和材料确认后校核字段字号与暖米白书写面积。

- **确认深墨绿与暖米白的最终色样、大面积印刷均匀性和桂黄细线对比**（后续验证）

  建议责任：设计负责人与包装供应商；时点：打样阶段

  推进方式：先提供本方案色值作为讨论基准，用色样或首轮打样对照盒面、标签和卡片；未确认前不把任一 HEX 写成确认印刷色，结果仅用于设计修订。

- **验证标签留白实际可写性、文字识别和礼盒运输固定**（后续验证）

  建议责任：设计负责人与包装供应商；时点：打样阶段

  推进方式：用 1:1 纸样或首轮打样检查书写、识别与晃动；结果仅用于设计修订，不承诺识别效果或运输表现。
