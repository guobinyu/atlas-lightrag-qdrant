## 整体概念

把真丝长巾设计成一条可系结的「墨绿雨巷手卷」：以深巷墨绿作为主色，中心保留大面积米雾白留白，雨丝用烟蓝细线沿长向行走，两端以米雾白单线桥拱收束，两个对角布置简化窗棂。主要识别点仍是「端部、边带、角部」在系结后露出，而不是中心满铺风景。配色修订为主推墨绿体系，另备米白底与墨绿深浅对比样供打样比较；整体保持含蓄、流动、克制的原创江南意象。

确认部分：现有能力为真丝丝巾、家居服与数码印花；仅开发丝巾或家居服，不生产酒类；用途以日常自用穿戴为主、轻礼赠为辅；主题为江南文化。假设部分：人群为关注东方审美与日常质感的成年女性；场景为通勤、周末出行和短途活动；佩戴位置包括颈部、包袋与肩部。该人群与场景仍为建议，需通过小样佩戴反馈和视觉偏好反馈验证，不作为已验证结论。

延续来源的原创创意叙事，不作史实考据：以「烟雨入巷、水影随行」为情感主线，把水巷、桥影、雨丝和窗棂处理为含蓄、流动、克制的氛围意象。中心留白像雾，雨丝像行走中的水汽，桥拱是远处一闪而过的轮廓，窗棂在打结时露出秩序感。所有意象均为原创设计语言，不指向具体地点、人物、典故或历史复原；不声称复原某段江南历史，也不把文化意象写成已验证的地域事实。

## 视觉设计

**故事与视觉转化（策划建议）**

- **雨丝让画面产生行走中的流动感** → 细密斜线、点阵与断续短线，线宽建议0.6–1.0mm，打样可调 → 长巾中段30%–70%L偏一侧纵向延伸，向两端逐渐疏密变化

  表达理由：借丝绸垂坠感表现雨雾流动；偏侧布置避免中心满铺，系结后仍保留方向性纹理。

- **桥影作为江南水巷的含蓄符号** → 重复的单线半圆拱与短横线，拱高建议3%–5%W → 长巾两端各12%L的收束带，并延伸到一侧边带

  表达理由：用节奏化线条替代写实桥梁，在端部和垂坠边形成辨识点，又不过度叙事。

- **窗棂提供秩序感，便于日常搭配** → 简化方格、错位网格与小面积留白 → 两个对角各14%W×10%L区域，建议置于A端右下与B端左上，不四角满铺

  表达理由：角部在系颈或包袋打结时更易露出，兼顾文化表达与日常实用性。

- **水波呼应丝绸光泽** → 3–5条墨绿与雾青灰蓝的低对比渐变波纹与柔和色带 → 两侧各8%W边带、中心过渡区与两端收束带

  表达理由：形成柔和层次，让不同系法下都有完整色带，同时降低高密度图案带来的视觉拥挤。

- **雾的留白让画面有呼吸感** → 大面积无装饰米雾白区域，仅保留极浅渐变 → 中心约60%W×46%L范围

  表达理由：让长巾在日常佩戴中不显杂乱，并使端部与角部图案成为更清晰的识别点。

**图案与构图**

以纵向连续画面为主体，W指短边宽，L指长向长。160×50cm与180×65cm采用同一结构比例，不拉伸变形：中心约60%W×46%L保持米雾白大留白；两侧各8%W为墨绿水波边带；两端各12%L为墨绿桥拱收束带；两个对角各14%W×10%L布置窗棂角花；中段30%–70%L偏一侧组织雨丝。视觉层级为：远看先见墨绿边带、端部米白拱线和整体留白，近看才见雨丝与窗棂；系结后优先露出端部、边带和一个角部。留白面积建议不低于35%，装饰线不进入中心，避免写实风景堆叠。

**配色建议**

- 主色：深巷墨绿 `#3F4B44` — 主推版的长巾边带、端部收束带与角部底纹，建议约占45%–48%；作为低饱和墨绿体系的主色，连接水波、桥拱与整体节奏。

- 辅助色：米雾白 `#F3EEE4` — 中心呼吸区、桥拱线、窗棂留白和米白底备选版主体，建议约占36%–42%。

- 辅助色：雾青灰蓝 `#9FAFAD` — 水波渐变、雨雾过渡与低对比层次，建议约占10%–13%；在墨绿主色下作为辅助色，不成为大面积底色。

- 点缀色：烟蓝 `#72878C` — 雨丝细线、点阵与端部短横线，建议约占5%；用于拉开层次，不单独成为大面积底色。

HEX 为概念配色建议，实际印刷与面料表现待打样确认。

**字体与文字层级**

产品名与主题字建议采用现代宋体风格，字重中等，字距5%–8%，用于D4正面和D5正面；主题短句可用轻量宋体或中性无衬线，字距8%–12%，用于D5背面；法定信息使用清晰中性无衬线，按合规排版。品牌字体未提供，当前以系统占位字体推进，具体字体授权待商家确认；不把建议字体写成已有品牌字体，也不假设品牌视觉规范已存在。

文字：巾面不置文案；图稿边注「烟雨巷影」与「[品牌署名]」仅为识别与署名位占位，不进入印花主体。

### 系结可见性示意与佩戴应用稿

交付标识：D2

版式：横向三栏并列：左栏颈部、中栏包袋、右栏肩部。每栏上方画折叠与打结位置示意，下方画露出区域检查图；底栏统一放「端部桥拱、角部窗棂、边带水波、中心留白」四项露出检查表。示意稿用灰线表示被折叠或遮挡区，用本方案墨绿、米雾白、雾青灰蓝与烟蓝色块表示露出区，不声称实际佩戴效果已获验证。

图案：颈部：对折成约5–7cm宽长条，绕颈一周后在侧前方单结，结位落在第2端部12%L内，垂下一端露出墨绿桥拱带与米白拱线，另一端露出一个窗棂角。包袋：对角折成三角带，绕包柄两圈后侧结，角部窗棂落在包柄外侧下方，端部墨绿桥拱在垂尾末段。肩部：沿长向披搭，前后错位，肩峰处保留大面积米雾白，墨绿水波边带沿肩线连续露出，一端露出端部拱线。

配色：#3F4B44、#F3EEE4、#9FAFAD、#72878C

文字：不置巾面文案；每栏角落标注「颈」「包」「肩」为示意功能字，不进入图案。

材料与工艺建议：建议用同规格坯布或纸样做折叠检查，重点看端部、角部与边带露出关系；最终尺寸、面料与卷边未确认前，打结位置和露出面积均需随打样调整；不把示意图写成实际佩戴效果或生产结论。

  建议责任：商家与合规负责人；时点：D4标签完稿前

  推进方式：设计仅完成版式与信息区占位，法定文案未确认前不进入标签完稿，不由设计师决定或编造。

- **数码印花宽幅、裁切对位、卷边供应、色彩还原、色牢度与缩水测试**（后续验证）

  建议责任：供应链与质检负责人；时点：首轮打样与D3配色完稿前

  推进方式：以供应商打样和测试结果判断图案密度、细线清晰度与配色是否需要调整，概念阶段不作可落地承诺。

- **建议人群与场景的小样佩戴及视觉偏好反馈**（后续验证）

  建议责任：产品与设计负责人；时点：首轮小样完成后、D2与主图案定稿前

  推进方式：先按建议人群与场景推进，收集小范围佩戴和视觉偏好反馈后再决定是否调整边角露出与配色，不把假设写成已验证结论。
